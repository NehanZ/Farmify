## Features ✨
- **User Authentication** (Signup/Login with Firebase)
- **Product Management** (Add/Edit/Delete farm products)
- **Real-time Database** (Firestore for live updates)
- **Responsive Design** (Works on mobile & desktop)
- **Seller Dashboard** (Manage inventory & sales)

## Tech Stack 🛠️
**Frontend:**
- React 18
- React Router 6
- Bootstrap 5
- React Bootstrap

**Backend:**
- Firebase Authentication
- Firestore Database
- Firebase Storage
